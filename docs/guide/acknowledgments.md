# Acknowledgments

castiel builds on open data and open tools. The catalogs bundled with the harness are generated from the following sources:

## MITRE ATT&CK

The bundled MITRE ATT&CK technique catalog (generated by `scripts/extract_attack_techniques.py`) uses [MITRE ATT&CK®](https://attack.mitre.org/) data from [attack-stix-data](https://github.com/mitre-attack/attack-stix-data). ATT&CK® is a registered trademark of The MITRE Corporation.

## Kali tools

The Kali tool catalog (`scripts/extract_kali_tools.py`) is built from the [Kali tools documentation](https://gitlab.com/kalilinux/documentation/kali-tools).

## Vulnerability intelligence

- CVE search and details come from the [CVE Program](https://www.cve.org/) search and CVE Services APIs.
- Known-exploited flags come from [CISA Vulnrichment](https://github.com/cisagov/vulnrichment).
- Public proof-of-concept code comes from [PoC-in-GitHub](https://github.com/nomi-sec/PoC-in-GitHub).

## Web search

Web search uses [FreeSerp](https://freeserp.ai/).
